# Full Stack Open Relational Databases

Blog backend for the Full Stack Open relational databases course exercises.

## Setup

1. Copy `.env.example` to `.env`.
2. Set `DATABASE_URL`, `TEST_DATABASE_URL`, and `SECRET`.
3. Install dependencies with `npm install`.
4. Start the app with `npm start`.

The app runs migrations on startup by default. You can also run them manually with `npm run migration:up`.
